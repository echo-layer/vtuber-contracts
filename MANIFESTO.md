# Project Manifesto

## 📢 Core Beliefs
1. **Simplicity over Complexity:** We strive for Single Source of Truth (one schema, many languages).
2. **Speed and Safety:** Leveraging Rust, Protobuf (proto3), buf, tonic, ts-proto, mypy-protobuf to achieve Backward compatibility (semver enforced per .proto package via buf breaking).
3. **Open Collaboration:** Our mission is Become the canonical typed boundary for the vtuber program — every cross-service value crosses through here, internal and external developers consume the same generated SDKs..

## 🎯 Our Aim
We build tools that empower developers to handle complex MLOps workflows with ease.
